LANGKAH LANGKAHNYA MENGGUNAKANNYA
1. Buka aplikasi IntelliJ IDEA.
2. Jika Anda sudah berada di halaman Project, buat atau pastikan struktur direktori folder proyek Anda sesuai dengan struktur package yang digunakan di kode (pbo.responsi).
3. Masukkan kelima file kode Anda (pengisi.java, tangki.java, pengisian.java, pembayaran_transaksi.java, dan Main.java) ke dalam folder src/pbo/responsi/ tersebut.
4. Di IntelliJ IDEA, buka menu File > Open, lalu pilih folder utama proyek Anda (ResponsiPBO) dan klik Trust Project jika muncul peringatan.
5. Di panel kiri (Project Explorer), pastikan seluruh file kode Anda sudah terbaca di dalam package pbo.responsi (biasanya ikon foldernya berwarna biru dengan tanda source root).
6. Pastikan Anda sudah mengatur JDK (Java Development Kit) dengan cara Masuk ke menu File > Project Structure (atau tekan Ctrl + Alt + Shift + S).Pada bagian Project SDK, pastikan sudah terdeteksi minimal Java versi 8, 11, atau versi terbaru yang Anda miliki di komputer. Klik Apply dan OK.
7. Di IntelliJ IDEA versi modern (termasuk 2026.3), proses compile berjalan secara otomatis (Auto-build) setiap kali Anda menyimpan perubahan file (Ctrl + S). Namun, Anda juga bisa melakukannya secara manual:
Pilih menu Build di bagian atas.
Klik Build Project (atau gunakan shortcut Ctrl + F9 pada keyboard).
Periksa panel Build Output di bagian bawah. Pastikan muncul tulisan Build: completed successfully tanpa ada pesan error merah.
LANGKAH LANGKAH MENJALANKANNYA:
1. Buka file Main.java di editor.
Cari ikon tombol hijau berbentuk segitiga di sebelah kiri baris public class Main atau di samping baris public static void main(String[] args).
Klik ikon tersebut, lalu pilih Run 'Main.main()'. atau dengan cara
2. Klik kanan pada file Main.java di panel Project sebelah kiri.
Pilih opsi Run 'Main.main()'.
